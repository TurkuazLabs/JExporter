# JExporter Modern v2.1.0

Bu paket iki proje klasorunu birlikte korur:

- JExporter: guncel modern proje
- JXporter: eski kaynak/backup proje

## Degisiklikler

- JExporter UI modern kart tabanli Swing arayuze guncellendi.
- AppConstants eklendi.
- ConfigManager sabit degerlerle sade hale getirildi.
- Log4j yok.
- Profile JSON yok.
- ConsoleOutputCapturer kaldi.
- JXporter silinmedi.

## Calistirilacak Proje

NetBeans uzerinde guncel calistirilacak proje:

JExporter

Ana sinif:

com.mycompany.jexporter.JExporter

## Not

JXporter eski kaynaklar ve tessdata icin korunmustur.
