# JExporter Restore v2.0.2

Temiz restore paketidir.

## Kurulum

1. Zip icindeki `JExporter_restore_v2_0_2` klasorunun icindeki dosyalari proje kokune kopyalayin.
2. `pom.xml` dosyasini degistirin.
3. NetBeans uzerinden Clean and Build yapin.
4. `tessdata` klasorune en az `tur.traineddata` dosyasi koyun.

## Notlar

- Log4j yoktur.
- Profile JSON yoktur.
- ConsoleOutputCapturer kalir.
- Basarili/basarisiz loglar konsola yazilir.
- Ana sinif: `com.mycompany.jexporter.JExporter`
